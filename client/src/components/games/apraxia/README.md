# Apraxia-Specific Games

This directory contains games designed for Childhood Apraxia of Speech (CAS) and other motor speech disorders.

## Purpose
- Motor planning for speech sounds
- Sequential movement practice
- Syllable and word production
- Prosody (rhythm, stress, intonation)
- Consistent practice with feedback

## Apraxia Treatment Principles

1. **High Repetition** - Multiple trials per session
2. **Multi-Sensory Cues** - Visual, tactile, auditory feedback
3. **Systematic Progression** - Simple to complex sounds
4. **Immediate Feedback** - Real-time accuracy scoring
5. **Consistent Practice** - Daily engagement tracking

## Game Types

1. **Syllable Practice** - CV, VC, CVC patterns
2. **Word Approximations** - Progressive shaping
3. **Phrase Building** - Multi-word combinations
4. **Prosody Training** - Stress and intonation
5. **Movement Sequences** - Articulatory transitions

## Key Features

- **Visual Phoneme Cues** - Mouth position diagrams
- **Slow-Motion Modeling** - Break down movements
- **Tactile Feedback** - Touch cues (if supported)
- **Video Self-Monitoring** - Record and review
- **Intensity Scheduling** - Frequent, focused sessions

## Research-Based Methods

Incorporates evidence-based apraxia treatment:
- Dynamic Temporal and Tactile Cueing (DTTC)
- Rapid Syllable Transition Treatment (ReST)
- PROMPT (Prompts for Restructuring Oral Muscular Phonetic Targets)
- Kaufman Speech Praxis Treatment
- Integral Stimulation Approach

## Progression Levels

1. **Level 1** - Single sounds (vowels, consonants)
2. **Level 2** - CV and VC syllables
3. **Level 3** - CVC words
4. **Level 4** - Two-syllable words
5. **Level 5** - Phrases and sentences
6. **Level 6** - Conversational speech
